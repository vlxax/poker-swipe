PokerSwipe — iPhone Auth UI Fix v2
====================================

Заменить в репозитории только:
js/pokerswipe-auth-bootstrap.js

Что исправляет:
- экран входа по email собирается заново в runtime, поэтому поле email не может исчезнуть из-за старой/перебитой CSS;
- для auth-экрана добавлены критические стили с высокой специфичностью;
- незалогиненный пользователь сразу видит полноценную форму:
  конверт + заголовок + поле email + кнопка;
- auth init больше не может держать приложение на загрузке бесконечно;
- magic-link callback поддерживает hash и query;
- ошибки входа возвращают пользователя в видимую форму email;
- отправка magic link имеет таймаут и понятную ошибку.

После загрузки:
1. Дождаться GitHub Pages deploy.
2. Полностью закрыть вкладку/PWA PokerSwipe.
3. Открыть заново.
4. На экране должны одновременно быть:
   ✉️
   ВОЙТИ В POKERSWIPE
   поле "твоя@почта.ru"
   кнопка "ПОЛУЧИТЬ ССЫЛКУ"

Если снова виден только конверт/кнопка без поля email — значит iPhone показывает старый закэшированный JS,
а не этот файл.

# PokerSwipe V38 — Player Dashboard

Полная переработка раздела «Ты».

Что удалено из видимого профиля:
- лестница рангов;
- прогресс к рангу;
- декоративные аватары за дистанцию;
- дублирующиеся старые Poker DNA / YOU блоки;
- несколько конфликтующих объяснений уровня.

Новый смысл раздела:
1. Как я играю сейчас?
2. Где моя главная повторяющаяся ошибка?
3. Какие части игры сильные / слабые?
4. Улучшаюсь ли я на последних решениях?
5. Что конкретно делать следующим?

Новый экран:
- уровень игры + форма + достоверность;
- главный текущий leak с размером выборки;
- Preflop / Postflop / Sizing / Discipline с sample и трендом;
- последние 20 решений: сильные, ошибки, blind spots;
- один конкретный следующий шаг;
- вход в свои раздачи.

Ранги остаются только в legacy-коде для совместимости старых данных, но больше не отображаются в «Ты».
Покерная логика решений не менялась.

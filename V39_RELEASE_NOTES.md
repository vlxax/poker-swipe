# PokerSwipe V39 — My Hands / Deep Postflop

Основной релиз: «Мои раздачи» + расширение аналитического слоя.

## Ввод раздачи
- Hero stack и Villain stack вводятся отдельно.
- Effective stack считается автоматически как min(Hero, Villain).
- Сохраняется полный контекст и линия по Preflop / Flop / Turn / River.

## Новый полный отчёт
- первая наиболее слабая улица;
- street-by-street разбор;
- pot odds там, где Hero facing bet;
- board texture;
- sizing interpretation;
- strategy mix ближайшей локальной модели;
- альтернативные линии вместо одного «правильного ответа»;
- отдельный разбор действий оппонента;
- если карты Villain неизвестны, приложение прямо сообщает ограничение;
- 2–3 переносимых урока из раздачи;
- кнопка на тренировку похожих спотов.

## Важное ограничение
PokerSwipe не маркирует локальные эвристические/atlas-модели как точный solver output.
Для настоящих точных EV/frequencies произвольного постфлоп-дерева в будущем нужен solver backend или лицензированная библиотека precomputed solutions.

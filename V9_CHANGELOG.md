# PokerSwipe My Ranges v9 — Skill Trainer

Изменено поверх v8 без удаления базы и assets.

- Новый главный экран «Сегодня»: readiness по фактически отвеченным вопросам и слабые ранее тренированные споты.
- История теперь используется для приоритета прошлых ошибочных UO-рук в следующей сессии.
- Три режима подготовки для UO: Учить / Экзамен / Быстро.
- Экзамен не раскрывает ответ после каждого вопроса.
- Сохраняется response time и показывается среднее время решения.
- Новый режим «Собрать рендж»: 169 рук, сравнение с источником, missed / extra, precision / recall.
- Любой из 1578 source-чартов можно открыть из «Споты» и отправить в Build Range.
- Сохранено честное разделение: source-label training для 1578 и strict poker-action training только там, где semantics подтверждены.
- Fisher–Yates вместо Math.random().sort() для основного shuffle.

Ограничения, которые v9 сознательно НЕ маскирует:
- 1578 source charts не превращены магически в 1578 подтвержденных poker-action charts; strict = 284.
- Source mixed/color weights не объявляются solver frequencies.
- Нет ICM, postflop narrowing или exploit model без соответствующих исходных данных.
- Readiness считается только по реально пройденным вопросам, а не заявляет знание непройденных 169 клеток.

POKERSWIPE — ЗАМЕНА ФРИКОВОЙ ДАМЫ

Что делает этот ZIP:
- заменяет старые sprite.png / sprite.json Фриковой дамы во всех 6 состояниях;
- correct / wrong / skeptical / idle / thinking / streak теперь визуально используют ОДНО доброе лицо;
- старые изображения с видимыми LUDO/генераторными знаками больше не используются в этих состояниях;
- структура путей сохранена, поэтому существующий freak-lady-reactive.js продолжает работать без переписывания логики.

Как загрузить:
1. Распакуй ZIP.
2. Загрузи содержимое в КОРЕНЬ репозитория PokerSwipe, сохраняя папки.
3. GitHub спросит о замене существующих файлов в assets/freak-lady/* — замени их.
4. После публикации GitHub Pages обнови страницу с очисткой кэша, если сразу виден старый ассет.

ВАЖНО:
- Для правильного ответа: доброе лицо.
- Для неправильного ответа: доброе лицо.
- Для среднего/пограничного ответа: доброе лицо.
- Для thinking / streak / idle: тоже доброе лицо, чтобы нигде не всплывали старые водяные знаки.

ВЫРАСТИ РЕГА — V2

СТРУКТУРА:
- index.html — экраны приложения
- style.css — весь дизайн
- data.js — вопросы и серии
- app.js — логика игры и сохранение

ЧТО УЖЕ ЕСТЬ:
- создание персонажа;
- выбор имени и образа;
- домашний экран;
- EV, банкролл, репутация;
- уровни и ранги;
- 10 префлоп-задач;
- награды и вердикты Фриковой Дамы;
- карта серий:
  Калининград, Сочи, Минск, Кипр, EPT, WSOP, Triton;
- профиль игрока;
- миссии;
- заглушка магазина;
- сохранение прогресса через localStorage.

КАК ЗАГРУЗИТЬ В GITHUB:
1. Выйди из режима редактирования пустого index.html кнопкой Cancel changes.
2. На главной странице репозитория нажми Add file → Upload files.
3. Распакуй этот ZIP на компьютере.
4. Перетащи в GitHub сразу четыре файла:
   index.html
   style.css
   data.js
   app.js
5. Нажми Commit changes.
6. Подожди обновления Cloudflare.

ВАЖНО:
ZIP целиком загружать в GitHub не надо. Сначала его распакуй.

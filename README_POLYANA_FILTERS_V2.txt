ЧТО ИЗМЕНЕНО В ПОЛЯНЕ:
- быстрые фильтры полностью убраны с экрана «Сегодня»;
- оставлена одна нормальная кнопка «ФИЛЬТРЫ»;
- полный фильтр содержит:
  • Игра: NLH / PLO / PLO5
  • Freezeout
  • Bounty (включая Mystery Bounty)
  • количество re-entry: Есть / 1 / 2 / 3 / 4+
  • Add-on: Есть / Нет
  • Late reg: Есть / Открыт сейчас / Закрыт
  • Уровни: значения строятся из данных афиши
  • Орг. взнос: 0 / до 1000 / 1001–1500 / выше 1500
  • Клуб: выпадающий список всех клубов сегодняшней афиши
- выбранные фильтры сохраняются в localStorage;
- есть «Сбросить»;
- число турниров обновляется после фильтрации;
- если совпадений нет, показывается нормальное пустое состояние.

ВАЖНО:
- анимация баннера Heads Up сохранена;
- Solver, Главная, Карта и раздел клубов не менялись;

  не отдаёт эти поля, приложение честно показывает, что данных пока нет.

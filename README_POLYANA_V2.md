
# PokerSwipe — Поляна 2.0 (MVP)

Это безопасный отдельный модуль. Он НЕ переписывает текущий index.html и не трогает solver.

## Что уже работает
- Сегодня / А–Я / Карта
- загрузка `data/moscow_schedule_today.json`
- загрузка `data/moscow_clubs_pokernomoney.json`
- сортировка турниров по времени
- фильтры NLH / PLO / Bounty / Freezeout / Freeroll / Re-entry / Late reg
- расширенные фильтры
- детали турнира
- исключение очевидных городов вне Москвы (Краснодар / Воронеж / Санкт-Петербург)
- без длинного блока «О клубе»
- карта на Leaflet/OpenStreetMap; точки появляются, когда в каталоге клуба есть `lat` + `lng`
- значения не выдумываются: если источник не дал параметр, показывается «Не указано»

## Как проверить
1. Распаковать ZIP в корень `poker-swipe`.
2. В репозитории уже должны существовать:
   - `data/moscow_schedule_today.json`
   - `data/moscow_clubs_pokernomoney.json`
3. Открыть `/polyana2.html` через GitHub Pages / Cloudflare Pages.

Локально через `file://` JSON fetch может блокироваться браузером — проверять через сайт/локальный сервер.

## Как подключать к production
Пока НЕ заменять текущую Поляну автоматически.
Сначала проверить `polyana2.html` на телефоне и MacBook.
После одобрения переносим контейнер экрана в production router и подключаем:
```html
<link rel="stylesheet" href="./polyana/polyana.css">
<script src="./polyana/polyana.js"></script>
```

## Что сознательно не сделано
- не добавлены выдуманные уровни/стеки/add-on
- не делается «уровень поляны»
- нет банкролл-рекомендаций
- полный московский каталог нужно расширить: текущий `moscow_clubs_pokernomoney.json` может быть неполным
- координаты клубов нужно добавить отдельным проверенным источником
- настоящие клубные афиши пока не подтягиваются автоматически

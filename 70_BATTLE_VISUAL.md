# REG BATTLE
## Визуальная концепция: PvE-покер против живого архетипа, а не ещё один квиз

# ВХОД — «ПОКЕРНЫЙ СТОЛ С ОППОНЕНТАМИ»

Вместо вертикального списка карточек — один условный стол.

Вокруг сидят 4 opponent cards:
🧓 ДЕД
☎ ТЕЛЕФОН
🪨 НИТ
🔥 МАНЬЯК

Не нужны детальные персонажи. Можно сделать стильные editorial avatars / emoji silhouettes / CSS portraits.

У каждого:
`MASTERY`
небольшой ring.

Тап по персонажу → он увеличивается, остальные уходят в blur/dim.

---

# DOSSIER

Экран напоминает досье, а не профиль RPG.

### ТЕЛЕФОН
`VPIP 61`
`PFR 8`

Ниже три строки:

✓ `много коллит flop`

🔒 `river tendency`

🔒 `bluff frequency`

Подпись:
**Сыграй ещё 3 руки, чтобы открыть наблюдение.**

Это создаёт прогресс знания.

# МИССИЯ

Не длинный текст.

Три counters:

`THIN VALUE   1 / 3`
`BIG VALUE    0 / 2`
`ЛИШНИЙ BLUFF 0 / 1 max`

Миссия визуально остаётся рядом во время серии, но очень компактно.

---

# ИГРА

Во время hand нет зелёных/красных verdict.

Стол + board + действия.

Решения фиксируются.

После street просто:
**ПРИНЯТО**

И следующая улица.

Это создаёт напряжение: пользователь не знает, «хорошо ли играет».

# ПОСЛЕ 3–5 HANDS — READ PHASE

Совершенно другая механика.

Три slider:

### FOLD FLOP
`РЕДКО ━━━●━━━━ ЧАСТО`

### RIVER BLUFF
`РЕДКО ━●━━━━━━ ЧАСТО`

### THIN CALL
`РЕДКО ━━━━━●━━ ЧАСТО`

Пользователь строит **свою модель** оппонента.

После на экран накладывается второе положение:
`ТВОЯ МОДЕЛЬ`
vs
`НАБЛЮДЕНИЯ`

Так READ становится реальным score.

# EXPLOIT PLAN BUILDER

**БОЛЬШЕ**

# Техническая реализация
- opponents = grid around CSS oval;
- dossier = ordinary cards;
- locked intel = localStorage counters;
- sliders = input range;
- plan builder = drag chips;
- mastery = SVG/CSS ring;
- никакого real-time AI opponent не требуется для первой версии.

# PokerSwipe Ranges v4 — GitHub Web Upload Small Files

Эта сборка специально разбита на небольшие файлы для загрузки через github.com → Add file → Upload files.

- Всего файлов: меньше 100.
- Все 1578 source charts сохранены.
- Каждый chart-assets-XX.js содержит только 25 изображений и заметно меньше предыдущих 3–5 MB чанков.
- Загружай папку `ranges-ui` целиком в корень репозитория рядом с `index.html`.
- Если старая `ranges-ui` уже есть — замени её файлами из этой сборки.
- Папка `charts` НЕ нужна.

Важно: не распаковывай содержимое `ranges-ui` прямо в корень — должна сохраниться папка `ranges-ui/`.

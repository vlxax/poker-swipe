# PokerSwipe — Мои ренджи v8 FULL TRAINING

Заменить в репозитории только папку `ranges-ui/` содержимым этой версии. `index.html` текущего полного приложения уже подключает `ranges-ui/main.js`, поэтому переписывать всё приложение не нужно.

## Что изменено в v8

- Все **1578/1578** source-чартов доступны из базы и запускают тренировку по меткам исходного чарта.
- Все 1578 уже имеют 13×13 / 169-cell представление.
- Для каждого source-чарта тест спрашивает не выдуманное действие, а **как рука отмечена в самом источнике**.
- `Call/Push` (615 чартов) теперь тренируется по исходным margin buckets: **5% / 10% / 15% / 20% запас и выше**, без ложного переименования этих цветов в CALL/JAM/FOLD.
- `nAI`, `LOW_PLAYABILITY`, `SOURCE_MIX`, `SOURCE_OTHER` сохранены как source-метки. Приложение не придумывает их покерный смысл.
- Для **284** чартов, где действие подтверждено строгим фильтром, дополнительно остаётся кнопка **«СТРОГИЙ ТЕСТ РЕШЕНИЙ»**.
- 60 UO-чартов по-прежнему остаются полностью структурированной интерактивной базой.

## Важное исключение источника

`B2_1506` — не сломанный parser. В оригинальном чарте действительно **0% / 0 из 1326 комбинаций**: все 169 клеток не окрашены. Он корректно присутствует в базе и может быть классифицирован как `НЕ ВЫБРАНО`, но у него нет положительного действия, которое можно содержательно тренировать.

## Что НЕ утверждает v8

Source-label quiz и poker-decision quiz — не одно и то же. Если смысл цвета источника не подтверждён, PokerSwipe проверяет **метку чарта**, а не придумывает `fold/call/raise`. Доли пикселей также не выдаются за solver frequencies.

См. `FULL_RANGE_TRAINING_REPORT_V8.json` для покрытия и ограничений.

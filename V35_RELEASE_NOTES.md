# PokerSwipe V35 — UX Reset

## Что изменено
- Полностью пересобрана главная страница вокруг одного главного действия: персональной тренировки на сегодня.
- Убрана витрина из множества равнозначных функций с первого экрана.
- Лик/выборка и текущая задача пользователя подняты выше каталога тренажёров.
- «Своя раздача» вынесена в отдельный заметный CTA как один из ключевых сценариев продукта.
- Вторичные тренажёры собраны в компактный блок «Другие тренировки».
- Карьерный прогресс уменьшен до компактного индикатора вместо большого рекламного блока.
- Навигация переименована: «ГЛАВНАЯ / РАЗДАЧИ / ТУРНИРЫ / ТЫ».
- Увеличена минимальная типографика служебных текстов и объяснений.
- Розовая палитра заменена на electric lime / chartreuse на тёмном фоне.
- Обновлены глобальные accent states, progress bars, selected states и bottom navigation.
- Версия сборки поднята до 35.0.

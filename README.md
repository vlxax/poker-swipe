# POKER SWIPE V22 — HAND REVIEW REBUILD

Полностью переделан третий инструмент во вкладке «МОИ».

Новое название: РАЗБОР РАЗДАЧИ.

Что изменено:
1. Больше нет километровой формы.
2. Разбор идёт в 3 коротких шага:
   - контекст: формат, позиции, hero cards, effective stack;
   - линия: одна улица за раз, board, pot, действия оппа/героя, размеры через sliders;
   - факты: showdown, рука оппа, результат, вопрос, optional read.
3. Карты выбираются тем же мобильным picker, что ALL-IN / PUSH-FOLD.
4. На линии видна компактная heads-up модель стола.
5. По каждой улице можно выбрать действия кнопками, а не печатать текст.
6. Финальный экран показывает:
   - главную точку, где сломалась линия;
   - score твоей линии;
   - score оппонента, если известна его рука;
   - улицы PRE/FLOP/TURN/RIVER отдельно;
   - действия обоих;
   - pot odds и exact equity против фактической руки, когда это возможно;
   - стратегический ориентир модели;
   - отдельный verdict Фриковой Дамы.
7. Новые сохранённые раздачи можно открыть повторно из «Недавних».

Сохранены все предыдущие изменения V21.2:
- Telegram width fix;
- mobile card picker;
- обновлённая быстрая сессия;
- cartoon fish avatars;
- более токсичный YOU;
- V21.1 diagnostic fix;
- Poker Brain V20.

# POKER SWIPE — GitHub-ready MVP

Загрузить в корень репозитория:
- index.html

GitHub Pages:
Settings → Pages → Deploy from a branch → main → /(root)

Что работает:
- кликабельная стартовая обложка, без внешних картинок;
- Tinder-свайпы: влево FOLD, вверх CALL/CHECK, вправо RAISE/BET;
- кнопки Fold / Call / Raise;
- 150+ генерируемых вариаций preflop + postflop спотов;
- MIX / PREFLOP / POSTFLOP;
- раздача дня;
- быстрая игра на 10 спотов;
- раздача смерти;
- XP, EV, репутация, streak;
- локальное сохранение через localStorage;
- профиль, leaks, accuracy, ачивки;
- Telegram WebApp SDK и имя пользователя, если доступно;
- демо-рейтинг.

ВАЖНО:
Общий рейтинг реальных пользователей нельзя честно сделать одним GitHub Pages.
Для него нужен backend/БД (например Supabase). Интерфейс под рейтинг уже есть.

# POKER SWIPE V10 — REG AUDIT BUILD

GitHub Pages / Telegram Mini App prototype. Для публикации положите `index.html` в корень репозитория.

## Что изменено по реговскому аудиту

- Onboarding: tap-through знакомство → ник → отдельная 10-спотовая диагностика по категориям, а не просто декоративный вход.
- Диагностика: отдельный набор задач, включая sizing; стартовый профиль разбивается по навыкам и не притворяется точным при маленькой выборке.
- PLAY: добавлена персональная карточка «У меня 5 минут» / «Сегодня для тебя», которая ведёт в наиболее полезную тренировку.
- Верхние метрики объясняются по тапу; персональные skill-показатели в YOU не рисуются, пока не набрана минимальная выборка.
- Poker Swipe: legal actions зависят от ситуации (чек/ставка вместо костыля CALL=check), 10-спотовые сессии, mixed/тонкий исход, контекстные CTA, увеличенные задержки, редкая проверка уверенности, повторные ошибки формируют лик.
- Sizing: обычный выбор размера + «зачем», multi-select допустимых сайзингов, сравнение двух рук, REG MODE со слайдером 0–150%, визуальная шкала полярности, category report.
- «Ну что опять не так?»: выбор конкретного действия внутри улицы, одна попытка, отдельная проверка причины, причинная timeline, реальный repair-step с новой линией и сравнением «было / стало».
- Daily: одна сложная многоуличная раздача, фиксация решения, время размышления, защита аргумента, «за / против», перенос концепции на контрольный spot, архив Daily и отдельный daily streak.
- «Лечить»: полноценный курс, а не 3 демо-кнопки — конкретные блеф-комбинации, value construction, pot-odds slider, blocker lab, контрольная; progress сохраняется.
- МОИ: сохранённые раздачи снова открываются; ввод карты улучшен; анализ больше не использует фальшивые фиксированные 82/74/58/46. Показываются вычислимые параметры линии (pot / bet / required equity / SPR при наличии данных) и качественные flags вместо выдуманного solver score.
- Быстрый расчёт: pot odds + all-in equity; карты для equity выбираются через визуальный picker, а не текст `As Ks`.
- Battle: PvE exploit campaign, разные сценарии для архетипов, случайная следующая рука вместо вечного `hands[0]`, постепенно открываемое досье, отдельные Theory / Exploit / Read, Mastery и история последних боёв.
- YOU: настоящее покерное досье; временной график skill, sample-size gating, Poker DNA с drill-down, динамический список ликов, кликабельные лики, confidence mistakes, только реальные «исправленные» навыки, работающая карточка «Что делать сегодня».
- Токсичный стиль Фриковой Дамы сохранён как акцент после полезного объяснения, а не вместо него.

## Важно про математику

Приложение не выдаёт статические персональные проценты за solver-данные. Pot odds считаются точно по введённым значениям. All-in equity в браузере оценивается Monte Carlo там, где нужен добор неизвестных карт. Для полноценного solver-backed EV, диапазонов и общей статистики поля в будущем нужен серверный слой/solver dataset.

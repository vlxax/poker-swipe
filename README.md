# Фриковая Дама — PRO prototype v1

Это новая версия без наложения текста и карт поверх готовых Figma-экранов.

## Что исправлено
- Главная кнопка Swipe Test — настоящая кнопка с press/tap эффектом.
- 15 разных рук генерируются кодом.
- Карты, позиция, стек, банк, стадия и ситуация меняются динамически.
- Fold / Call / Raise — реальные интерактивные кнопки.
- Для каждой руки у каждого действия есть отдельная оценка: MATCH / YELLOW FLAG / RED FLAG.
- Комментарий Фриковой Дамы меняется.
- EV, репутация и итоговый счёт пересчитываются.
- Финальная цитата зависит от результата.
- Нет дублирования карт, текста и кнопок поверх PNG.

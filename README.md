# POKER SWIPE V23 — ТУРНИРЫ

Новый самостоятельный раздел в нижней навигации:
PLAY · МОИ · ТУРНИРЫ · YOU

## Турнирный журнал
Пользователь может добавлять неограниченное количество турниров.

Для каждого турнира:
- онлайн / офлайн;
- любое название;
- дата;
- валюта USD / EUR / RUB;
- бай-ин;
- количество пуль;
- количество выбитых баунти;
- сумма выигранных баунти;
- призовые без баунти;
- место;
- размер поля.

Приложение автоматически считает:
- вложено = buy-in × entries;
- возврат = prize + bounty won;
- profit;
- ROI.

Есть:
- фильтры ВСЕ / ОНЛАЙН / ОФЛАЙН;
- переключение валюты без некорректного смешивания $/€/₽;
- сортировка новые / старые;
- карточки турниров;
- победа / финалка / ITM;
- редактирование и удаление;
- повторное открытие каждого турнира.

## YOU
В YOU добавлен только аналитический итог, без дублирования истории:
- число турниров;
- ITM%;
- количество финалок;
- profit и ROI отдельно по каждой валюте.

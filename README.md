# POKER SWIPE 7.0

Главные изменения:
- нижняя навигация: PLAY · МОИ · BATTLE · YOU;
- Daily открывается первым;
- PLAY персонализирует ленту под текущий leak;
- кнопка «ЛЕЧИТЬ» запускает серию по слабому тегу;
- после части RAISE появляется второй шаг с выбором сайзинга;
- «Мои раздачи» теперь собирают Hero/Villain positions, blinds/ante, действия обоих игроков, pot и sizing по улицам;
- пользовательский вывод формулируется как зона для проверки, а не как фальшивый solver verdict;
- BATTLE теперь работает локально на одном телефоне: 5 одинаковых spots, два игрока, скрытые ответы, финальное сравнение;
- технические backend/solver-дисклеймеры убраны из пользовательского интерфейса.

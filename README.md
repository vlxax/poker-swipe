# Фриковая Дама — merged prototype

Это версия, где **визуал взят из вашего Figma-файла**, а интерактивность работает кодом.

## Что работает
- Главный экран → Свайп-тест
- 15 разных рук
- Fold / Call / Raise
- MATCH / YELLOW FLAG / RED FLAG
- Разные реплики Фриковой Дамы
- Последняя 15-я рука → «Узнать результат»
- Финальный вердикт зависит от результата
- «Продолжить» возвращает на главную

## Как посмотреть
Просто откройте `index.html` двойным кликом в браузере.

## Как загрузить на GitHub Pages
1. Создайте новый репозиторий.
2. Загрузите `index.html`, папку `assets` и при желании `Untitled.fig`.
3. Settings → Pages → Deploy from a branch → `main` → `/root`.
4. GitHub выдаст публичную ссылку.

`Untitled.fig` лежит в архиве как исходник вашего макета.

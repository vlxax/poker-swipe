# POKER SWIPE V20 — PRODUCTION YOU

YOU:
- полностью новый аналитический профиль;
- никакого лечения / Heal внутри YOU;
- PREFLOP / POSTFLOP / SIZING: зелёный, жёлтый или красный по реальным накопленным решениям;
- рейтинг улиц по частоте ошибок;
- confidence: «уверен и прав» / «уверен и мимо»;
- график формы;
- токсичный динамический вердикт Фриковой Дамы;
- при малой выборке приложение не делает выводов;
- аватар развивается по дистанции: маленькая рыба → рыба → фугу → акула;
- пользователь может выбирать уже открытый аватар.

Главная:
- убрана отдельная creator-строка;
- приветствие/имя остаётся крупным;
- developer/GTO-status и build-информация скрыты;
- Daily: смысл + DONE после выполнения;
- Рентген: короткое русское объяснение;
- 5 минут: отдельный динамичный визуал + задания на основе ошибок;
- сокращены англоязычные и технические подписи.

Brain V20:
- 146 016 логических preflop reference states;
- 12 000 параметризованных postflop reference states;
- 169 классов стартовых рук, стеки 5–40BB, 6 позиций, 4 семейства preflop-ситуаций;
- postflop: текстура доски / SPR / положение / размер давления.
Это внутренний reference-layer тренажёра. UI не показывает пользователю разработческую информацию.

# POKER SWIPE 5.0

Готовая статическая версия для GitHub Pages.

## Что изменено
- Убрана дублирующая «Быстрая сессия».
- Poker Swipe = action trainer.
- «Сколько, гений?» = отдельный sizing trainer.
- «Где началась хуйня?» = поиск первой ошибки в полной раздаче.
- Daily остаётся отдельным ежедневным крючком.
- «Раздача смерти» теперь не отдельная дублирующая игра, а глубокий разбор.
- Green/Yellow/Red заменены в пользовательском языке на «РЕГ / ЖИТЬ БУДЕШЬ / ПАНТ», цвет остаётся в glow.
- Hall of Shame, Poker DNA, leak tracking, streak, редкие interrupt-реакции.
- Reg Battle показан как будущий сетевой режим без фальшивых соперников.
- EV-loss помечен как обучающий скоринг, не solver output.

## Важно
Для настоящих Daily-процентов, Challenge Links, дуэлей, общего рейтинга и сравнений с полем понадобится backend.

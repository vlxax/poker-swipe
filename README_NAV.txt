POKERSWIPE — 3D BOTTOM NAV FROM FIGMA MAKE

Это отдельная визуальная надстройка только для нижней навигации.

Файлы:
- poker3d-nav.js
- poker3d-nav.css

Что делает:
- берёт существующие 5 кнопок PokerSwipe внутри .nav [data-nav]
- НЕ меняет data-nav
- НЕ меняет существующие обработчики переходов
- заменяет только визуал иконок/подписей
- использует 5 SVG-иконок из присланного Figma Make проекта:
  Главная / Раздачи / Поляна / Мои турниры / Ты
- активная вкладка получает лаймовую верхнюю линию, glow и 3D-цвет
- неактивные SVG становятся тёмно-серебристыми
- центральная Поляна чуть крупнее
- MutationObserver восстанавливает SVG, если старый код Поляны пытается снова вставить ♛

ПОДКЛЮЧЕНИЕ:
Добавить в index.html ПОСЛЕ основных CSS/JS PokerSwipe:

<link rel="stylesheet" href="poker3d-nav.css">
<script src="poker3d-nav.js" defer></script>

Безопасность:
Этот пакет не содержит index.html, Polyana, solver, данные или другие разделы.
Он не должен заменять текущую навигационную логику — только её внешний вид.

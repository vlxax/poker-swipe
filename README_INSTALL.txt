-------
Готовый визуальный слой для существующего раздела «Мои турниры».

Он НЕ заменяет:
- нижнюю навигацию PokerSwipe;

- расчёт ROI / PROFIT / bounty;
- localStorage / данные пользователя;
- маршрутизацию.

Он меняет ТОЛЬКО визуальный слой «Мои турниры» в направлении Stitch:
obsidian / charcoal + electric lime + premium analytics.

КАК ВСТАВИТЬ ЧЕРЕЗ CURSOR
--------------------------
Самый безопасный способ:

1. Перетащи этот ZIP в Cursor в проект poker-swipe.
2. Распакуй его в отдельную временную папку.
3. Дай Cursor текст из CURSOR_PROMPT.txt.
4. Пусть Cursor:
   - скопирует CSS и JS в корень проекта;
   - подключит CSS/JS ПОСЛЕ текущих PokerSwipe visual layers;
   - проверит экран «Мои турниры»;
   - НЕ меняет нижнюю nav;
   - делает отдельный PR.

НЕ НУЖНО вручную заменять index.html целиком.

ВАЖНО
-----
Stitch code.html содержит отдельную Three.js-фишку.
Я оставила её как reference, но НЕ подключала в прод напрямую:
она тянет внешнюю библиотеку Three.js и может ухудшить мобильную производительность.
Сначала делаем дорогой визуал нативным CSS. Потом, если захочешь, отдельно добавим
3D-фишку как лёгкий decorative hero element.

Если в текущей версии PokerSwipe названия DOM-классов турниров отличаются,
Cursor должен сопоставить их с существующими t23* элементами, НЕ переписывая бизнес-логику.

POKER SWIPE — ПОЛЯНА / МГНОВЕННАЯ КАРТА

Зачем этот пакет:
Старая версия геокодировала адреса прямо в браузере пользователя.
Из-за этого было "26 из 65 · ещё 21 · не найдено 18" и точки появлялись постепенно.

Новая схема:
GitHub один раз заранее готовит координаты -> polyana/club_coords.json
Пользователь открывает карту -> браузер делает ОДИН fetch готового JSON ->
все уже подготовленные точки появляются сразу.

ЗАГРУЗИТЬ В РЕПОЗИТОРИЙ С СОХРАНЕНИЕМ ПАПОК:
1. polyana/map.html
2. polyana/build_map_coords.py
3. polyana/club_coords.json
4. .github/workflows/polyana-map-coords.yml

После загрузки workflow запустится сам из-за push.
Также его можно вручную запустить:
GitHub -> Actions -> Build Polyana map coordinates -> Run workflow.

ВАЖНО:
Первый запуск GitHub Action может занять около минуты или нескольких минут,
потому что 65 адресов готовятся ОДИН РАЗ НА СЕРВЕРЕ.
Это больше никогда не ждёт пользователь.

После успешного Action:
polyana/club_coords.json будет содержать все адреса, которые удалось однозначно найти.
При следующих открытиях карты НЕТ Photon/Nominatim запросов с телефона.

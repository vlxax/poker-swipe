POKERSWIPE — ПРОФИЛЬ «ТВОЙ ПОКЕРНЫЙ ПОЧЕРК»

Эта версия собрана по продуктовому аудиту из ветки пользователя.

Главное изменение:
- профиль больше не выглядит как отчёт по 11 миниапкам;
- основной экран отвечает на 3 вопроса: что получается, где паттерн ошибки, что изменилось;
- центральный элемент — карта игры: Префлоп / Постфлоп / Сайзинг с раскрытием конкретных тем;
- «Твоя опора» и «Точка роста» показывают выборку и доказательства;
- «Что изменилось» сравнивает только два полных окна по 20 решений внутри одной зоны;
- уверенность, активность и методология спрятаны в раскрываемые детали;
- турнирные результаты не используются как доказательство качества решений;
- частота call/raise не интерпретируется как психологический/игровой стиль;
- уверенная ошибка не называется «дорогой» без надёжного EV;
- Skill оставлен только как маленький вторичный бейдж, если он уже есть в состоянии приложения.

Файлы для замены:
1. profile.js
2. profile.css

Важно: profile.js должен оставаться единственным активным владельцем window.renderProfile. Не подключать его вторым wrapper поверх старого профиля.

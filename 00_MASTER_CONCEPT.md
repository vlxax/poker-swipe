# POKER SWIPE — VISUAL / INTERACTION SYSTEM V1
## Креативный аудит: как сделать каждый режим отдельной «игрой», не превращая проект в тяжёлый game engine

### Главная проблема текущего UX

Poker Swipe уже имеет собственную форму: быстрый покерный spot → одно решение → мгновенная реакция. Его не трогаем.

Остальные режимы нельзя строить по одному шаблону:
`карточка → 3–6 кнопок → текст → следующая карточка`.

Даже если теория разная, пользователь физически делает одно и то же. Через несколько минут мозг перестаёт воспринимать режимы как разные активности. Продукт превращается в красивую викторину.

### Новое правило продукта

**Каждый режим тренирует отдельный покерный навык отдельным главным жестом.**

| Раздел | Что тренирует | Главный жест | Визуальная метафора |
|---|---|---|---|
| Poker Swipe | быстрое решение | тап | Tinder / лента |
| Sizing | размер и цель ставки | тянуть фишки / slider | реальный стек и банк |
| Ну что опять не так? | hand review | исследовать timeline / заменить node | расследование |
| Daily | глубокое решение | смотреть replay + раскладывать аргументы | событие дня / один стол |
| Лечить | исправление лика | разные микроигры | лаборатория |
| Мои | разбор своей руки | собирать hand history | покерный стол / журнал |
| REG BATTLE | exploit | читать соперника + строить план | PvE-досье |
| YOU | прогресс | исследовать skill tree / timeline | личное покерное досье |

### Визуальная система

Общая айдентика сохраняется:
- тёмный графитовый фон;
- бордовый/розовый акцент Фриковой Дамы;
- белый высокий контраст;
- зелёный / жёлтый / красный только как смысловая реакция;
- ♥ ♦ красные, ♠ ♣ чёрные на светлых картах;
- крупная типографика;
- минимум «игрушечных» 3D-иконок;
- больше ощущения fashion/editorial + poker tool, меньше «игра переодевалка 2007».

Но у каждого режима появляется **свой локальный визуальный язык**:
- Sizing — фишки и шкалы;
- Review — вертикальная схема раздачи;
- Daily — кинематографичный стол и раскрытие улиц;
- Heal — лабораторные микроигры;
- My Hands — конструктор стола;
- Battle — персонаж/досье/миссия;
- YOU — аналитическая карта навыков.

### Ограничение для разработчика

На одном экране — **один главный жест**.

Не делать одновременно:
- slider;
- 6 кнопок;
- drag&drop;
- chart;
- длинный текст.

Сначала действие. Потом реакция. Потом короткий вывод. Детали — по тапу.

### Технический принцип

Всё ниже можно реализовать обычными:
- HTML;
- CSS Grid/Flex;
- CSS transforms/transitions;
- Pointer Events (`pointerdown / pointermove / pointerup`);
- `<input type="range">`;
- SVG для простых линий/графиков;
- localStorage;
- JSON-базами Poker Swipe.

Без Canvas/WebGL/Unity.

### Микрокопирайт Фриковой Дамы

Формула:
1. факт;
2. объяснение;
3. один фирменный укол.

Не писать шутку вместо анализа.

Пример:
> Для колла нужно 31% equity. По этой линии естественных блефов недостаточно.  
> **Вера в людей опять обогнала математику.**

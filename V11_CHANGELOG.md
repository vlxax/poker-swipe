# PokerSwipe Ranges v11 — Skill Split

## Исправлено по аудиту v10

- Mastery разделён по навыкам: **Граница** и **Решения** больше не смешиваются.
- Learn / Exam / Rapid учитываются разным весом; мгновенный разбор ошибок не раздувает основной mastery.
- Неизученные руки больше не считаются «просроченными» — теперь NEW и DUE разные состояния.
- Новый консервативный skill score штрафует за маленький coverage.
- Adaptive selector теперь держит баланс: слабые/due, новые и обычный review, а не зацикливается только на ошибках.
- Для всех 1578 structured charts boundary стал **семантическим + матричным**, а не только геометрическим.
- Study показывает **размер ренджа %, combos, состав по hand families**.
- Добавлена heatmap знаний прямо на 13×13: unseen / shaky / weak / mastered.
- Build Range теперь показывает ошибки и в hand classes, и в реальных **combos**.
- Stack Diff теперь показывает не только IN/OUT, но и руки, у которых **изменилось действие**.
- В каталог выведены все 11 семейств source spots, а не только часть.
- RFI теперь подписан как **первый в банк / до нас все сфолдили**, вместо внутреннего UO-языка.
- Rapid получил визуальный 5-секундный countdown.
- Results больше не дают эмоциональный вердикт «сильно» после маленькой выборки; показываются session accuracy, coverage и отдельный skill.
- «Разобрать ошибки» помечается correction-сессией и не считается полноценным подтверждением mastery.

## Честные ограничения

- Неподтверждённые FOLD/CALL/RAISE по source-картам по-прежнему не выдумываются.
- Mixed pixel shares не называются solver frequencies без доказанной семантики источника.
- ICM, EV-loss, postflop narrowing и opponent-specific models требуют дополнительных исходных данных и не были сфабрикованы.
- Полноценный browser E2E в этом окружении не прошёл: Chromium зависает на DBus/zygote до отдачи DOM. Unit/data/static проверки ниже прошли.
